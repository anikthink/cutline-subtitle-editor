# Cutline — Open seam

Selected direction: option 03 from the twenty splice refinements.

The symbol preserves the selected two equal subtitle bars and wide diagonal seam.
The SVG files use four filled paths, without fonts, masks, scripts, or external resources.

- Amber: #E7B64B, for dark backgrounds.
- Dark: #111111, for light backgrounds.
- White: #FFFFFF, for dark or photographic backgrounds.
- CurrentColor: for inline SVG in an interface; set its CSS color.

The PNG files are 512 × 512 pixels with transparent backgrounds.
Use SVG for other sizes. Keep the original proportions and allow clear space
of at least half a bar thickness around the visible mark. A minimum display
size of 16 × 16 pixels is the starting point; inspect it on the actual surface.

The application keeps its existing typeset Cutline wordmark. These files
contain the symbol only.
